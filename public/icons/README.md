# Instruções para gerar os ícones PNG

Como o sistema precisa de ícones PNG em vários tamanhos, você pode:

## Opção 1: Usar o site realfavicongenerator.net (Recomendado)
1. Acesse https://realfavicongenerator.net
2. Faça upload do icon.svg (que está em public/icons/)
3. Baixe o pacote de ícones gerado
4. Extraia na pasta public/icons/

## Opção 2: Usar ícones temporários
Por enquanto, o PWA funcionará com o SVG.
Os ícones PNG são necessários apenas para melhor compatibilidade.

## Opção 3: Gerar manualmente
Use qualquer editor de imagem (Figma, Canva, Photoshop) para:
- Abrir o icon.svg
- Exportar nos tamanhos: 72, 96, 128, 144, 152, 192, 384, 512 pixels
- Salvar como icon-{tamanho}x{tamanho}.png

## Tamanhos necessários:
- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png
